# mdchk config

Use the `config` command group to work with mdchk configuration. Its subcommands inspect configuration without running Markdown rules.

```text
mdchk config <subcommand> [options] [arguments]
```

| Subcommand | Purpose | Guide |
| --- | --- | --- |
| `validate` | Find and validate project configuration files | [Config validate](config/validate.md) |

Run `mdchk config --help` to see the group's commands. The [global options](../index.md#global-options) also apply.
