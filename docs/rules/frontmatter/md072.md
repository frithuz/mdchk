# MD072: Metadata key ordering

Status: planned for implementation.

Area: [Frontmatter](index.md).

## Behavior

Require keys in each recognized metadata mapping to appear in ascending Unicode code-point order. Sequences retain their order.

Run only with frontmatter recognition enabled. Metadata is otherwise protected from body rules. Recognition follows the [YAML/TOML frontmatter contract](../../engineering/frontmatter.md); JSON headers are deferred. Structured key inspection requires the corresponding metadata parser.

Retain current recursive=false and case_sensitive=true defaults. Compare decoded keys in Unicode code-point order; case-insensitive mode uses Unicode case folding, retaining source order for equal folded keys. Recursive mode checks nested mappings, including mappings inside sequences, without reordering sequence elements.

Allow bounded acyclic aliases. Treat merge keys, custom tags and cycles as unsupported for semantic metadata analysis, with incomplete affected coverage. No includes or execution.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

recursive: boolean, false; case_sensitive: boolean, true.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
---
z: 1
a: 2
---
````

Accepted input:

````markdown
---
a: 2
z: 1
---
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Reorder only complete independent entries, preserving exact value spelling, quoting, line endings and inline comments. Initially leave affected blocks containing standalone comments or YAML anchors/aliases report-only. Never move TOML table declarations, dotted-key assignments or array-of-table elements. Reparse candidates to verify unchanged values and sequence order; reliable ordering violations may still be reported where automatic correction is unavailable.

See the [metadata contract](../../engineering/frontmatter.md#metadata-values-and-corrections).

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
