# MD033: Embedded HTML

Status: analysis and configuration implemented for CommonMark and GFM.

Area: [Html and comments](index.md).

## Behavior

Report each complete named CommonMark opening, closing or self-closing tag in
actual parser-owned HTMLBlock or InlineHTML content, except allowed names.
Names use ASCII letters followed by ASCII letters, digits or hyphens, including
custom names. Opening and closing occurrences report separately; self-closing
occurrences report once. The fixed message is `Embedded HTML tag is not allowed.`
Each finding covers the full original tag from `<` through `>` with an exclusive
end, including original container-prefix gaps in multiline envelopes. Recognition
uses mapped logical content, so quoted `>` does not terminate a tag.

Comments, processing instructions, declarations and CDATA are opaque exemptions;
their payload never supplies tags. Their closing-line tails are inspected exactly
once. Attributes containing tag-like text do not create additional findings.
Actual pre/script/style/textarea raw payload is protected, including nested tags
inside pre. A CommonMark form-1 block ends at any of its four literal closing
tags regardless of opener or quote/comment-like payload; the actual closer and
tail remain eligible. Other genuine raw lifetimes persist across owners and
containers. Independently owned inline tokens require the parser's private raw
transition proof; complete tokens inside a form-6/7 mapped owner provide local
recognition proof. Actual opaque tokens and complete quoted attributes cannot
manufacture a cross-owner closer. No browser raw-name or foreign-DOM model is used.
GFM rendering filters do not remove authored eligible occurrences.

Actual HTML in Link labels is eligible. Entire Image descriptions and their raw
transitions are excluded. Code spans/blocks/info, URL/title/autolink fields,
retained reference definitions and recognized metadata are protected. Escapes
and entities never create tags; ordinary malformed Markdown Text is not scanned.
A complete raw opener unclosed at EOF remains a normal eligible opener.

A failed named candidate inside an actual HTMLBlock outside protected payload
makes the entire MD033 inventory unavailable, including earlier findings, with
explicit context-unavailable coverage. It is not a successful empty check or an
internal error. Shared incomplete metadata/syntax coverage still applies.

## Configuration

Default enablement: Disabled. Enable explicitly where embedded HTML is unwanted.
`allowed_tags` defaults to an empty string list. Match whole source names using
ASCII case folding and equal byte length only, without trimming or decoding.
Matching exempts opening, closing and self-closing tags of that name; it does not
allow an enclosing block's other tags or change raw protection.

The existing string-list domain remains permissive. Empty, malformed, non-ASCII,
whitespace, bracket/slash and NUL entries are accepted but cannot match a source
name. Duplicates remain preserved and harmless. Typed Go invalid-UTF8 strings
are likewise accepted but unmatchable. For example, `SPAN` allows span tags;
`ſpan`, ` span `, `<span>` and `/span` do not. Null, scalars, mixed-type lists,
unknown options and invalid shared booleans reject even when disabled.

```yaml
version: 1
rules:
  MD033:
    enabled: true
    allowed_tags: [SPAN, x-card]
```

All [shared settings](../index.md#configuration-and-findings) apply. Full original
context precedes finding-START directive suppression and inspection intersection;
hidden or unselected openers still determine later raw protection.

## Examples

`<span>Text</span>` reports two full-tag ranges, [0,6) and [10,17), unless span is
allowed. `<br/>` reports once. `<pre><b>x</b></pre>` reports only pre and /pre.
`<script>"<b>"</script><i>` reports script, /script and i. `Text`, a real comment,
inline code containing `<b>`, and `![<b>](image.png)` are accepted.

## Correction policy

Permanently report-only (NoFix). HTML may provide required rendering behavior.
No edits, eligibility, previews or corrected contents are produced. MD047 remains
the sole current correction producer; its separately validated newline correction
preserves manual MD033 findings on candidate and saved views.

## Validation

Reusable frozen analysis fixtures cover both flavors, all seven HTML block
forms, named grammar, options, raw/opaque tokens, ownership exclusions, Unicode,
TAB, LF/CRLF/CR, nested containers, incomplete owners and precise source ranges.
Original operation authority, detached outputs, finite precharging and atomic
publication checks also cover empty, clean, allowed and protected inputs.
