# MD040: Missing fenced block language

Status: analysis and configuration implemented for CommonMark and GFM.
Permanently report-only; no automatic correction is offered.

Area: [Code blocks](index.md).

## Behavior

Report actual fenced code blocks with a missing language identifier or a language
outside a nonempty `allowed_languages` list. Each violating block has one finding.
A payload is not required; valid unclosed fences are checked at their actual
parser boundary. Indented code and inline code are not fenced blocks.

The language is the first nonempty token of the parser's already-decoded info
string, separated only by ASCII SPACE/TAB. Compare that whole token exactly and
case-sensitively. Do not infer aliases, decode twice, or use a later token as a
replacement. Unicode whitespace and an entity-decoded newline are ordinary token
characters for this rule; this is distinct from renderer language-word selection.

Additional fence attributes do not substitute for a language. MD040 reserves any
first token beginning with ASCII `{` as missing language, including `{#id}`,
`{.go}`, `{=html}`, `{}`, and malformed `{oops`. This is a finite lexical rule,
not an attribute grammar: no balancing, class extraction or raw-format exemption
is performed. An escaped or entity-decoded leading brace has the same treatment.
`go {#id}` selects `go`; `{#id} go` remains missing. Bare `.go`, `#id`, `key=value`,
embedded braces and Unicode brace lookalikes remain ordinary literal labels.

Missing language reports a zero-width position immediately after the original
opening fence marker, before any padding or info, with the message:

> Fenced code block requires a language identifier.

A disallowed language reports its smallest contiguous original-source range:

> Fenced code block language is not allowed.

Later info and surrounding literal padding are excluded. Original escapes,
entities and normalized characters are indivisible source contributors, so the
range preserves their complete spelling. No diagnostic offset splits a UTF-8
scalar or CRLF. Nested container prefixes and LF/CRLF/CR retain original source
coordinates. These observations do not authorize insertion or replacement edits.

Recognized opaque headers, whole Images, HTML-owned spelling and actual raw
lifetimes stay protected. Unknown necessary language, ownership or source mapping
withholds the complete inventory, including earlier provisional findings, with
explicit reduced coverage:

> Fenced-language context is unavailable; the complete MD040 inventory is withheld.

Known allowed labels need no diagnostic mapping, and irrelevant unknown context
after the last potential finding does not create a deficit. Full ownership is
resolved before directive suppression and inspection focus. A withheld inventory
proves neither a used suppression nor complete absence of findings.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

allowed_languages: string list, empty; an empty list permits any nonempty,
nonreserved label. A nonempty list permits only exact matches. Missing language
always violates, even if the list contains `""` or an attribute-like token.

A custom list replaces the default. Duplicate elements do not multiply findings.
Empty, Unicode, whitespace-containing and control-containing strings retain the
shared permissive string-list domain; configured values are not trimmed or folded.
Wrong types, nulls, invalid shared settings and unknown options reject even when
the rule is disabled. An empty option mapping retains default-disabled behavior.

All rules also accept the [shared settings](../index.md#configuration-and-findings).

## Examples

Violating input:

````markdown
```
Example
```
````

Accepted input with the default empty allowlist:

````markdown
```text
Example
```
````

With `allowed_languages: [go]`, `go` is accepted and `Go` or `ruby` is reported.

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; do not invent a language. MD040 produces no edits, previews,
corrected documents or deferred fix proposals. MD047 may independently add a
terminal newline, after which remaining MD040 findings refer to that candidate
snapshot. MD040 retains permanent `NoFix` metadata.

## Validation

Reusable literal fixtures cover both formats, every option, exact original ranges,
protected content, nested containers, Unicode, LF/CRLF/CR, decoded labels and
attribute-like boundaries. Separate checks cover directives, unknown inventory,
original authority, interruption, strict configuration and native manual workflows.
MCP transport parity remains downstream; no correction support is implied.
