# MD079: Whitespace in Quarto chunk labels

Status: planned for implementation.

Area: [Code blocks](index.md).

## Behavior

Report Unicode whitespace in executable Quarto chunk labels declared in headers or label options.

Use [Quarto interpretation](../../engineering/integrations.md#quarto-chunks) with `integrations.quarto.enabled: true`, independently of this rule enablement. Initially support `r`, `python` and `julia`; initial `#|` body labels override header labels, including blank overrides. MD078 checks the effective label and exact case-sensitive uniqueness across languages. MD079 checks Unicode whitespace in every declared label, including overridden labels. `eval: false` does not exempt a chunk. Never execute or rename code.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

enabled: false.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
```{python}
#| label: my example
print(1)
```
````

Accepted input:

````markdown
```{python}
#| label: my-example
print(1)
```
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; renaming labels may break references. Require explicitly enabled Quarto recognition.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
