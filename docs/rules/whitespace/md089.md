# MD089: Spacing between CJK and Latin text

Status: analysis and configuration implemented for CommonMark and GFM; manual findings only.

Area: [Whitespace](index.md).

## Behavior

Require a space between physically adjacent original CJK ideographs and Latin
letters or ASCII digits in prose. Under the pinned Go Unicode 17.0.0 tables,
CJK means Han intersect Ideographic; Latin means Latin intersect Letter; digits
mean ASCII `0` through `9`. Supplementary and compatibility ideographs and
ideographic zero participate. Radicals, iteration marks, kana, Hangul and fullwidth
digits do not. Accented and fullwidth Latin letters participate.

Every intervening scalar is a barrier, including combining marks and variation
selectors. No normalization or grapheme stitching occurs: `中é` reports before
`e`, while `é中` does not. CJK punctuation remains separate from these classes.

Final Paragraph, Heading (including Setext), and GFM header/body TableCell Text
supply prose, including nested lists/quotes and ordinary link labels/image
alternatives. Only Exact authored contributions participate. Physical source gaps,
markup delimiters, entities, escapes, normalized contributions, code, comments,
HTML and breaks prevent bridging. Thus `**中A**` reports internally, while
`中**A**` and `**中**A` do not. Contiguous Exact contributions can cross segment
boundaries in the same prose owner.

Parser-recognized angle autolinks and bare GFM links, hidden destinations/titles,
reference definitions, code and raw HTML payload are protected. Ordinary tags are
barriers without hiding their eligible Text children. Raw protection survives
owner boundaries; image alternatives have isolated raw state. URL-looking Text
unrecognized by the selected parser remains prose: bare
`https://example.com/中A` is protected in GFM and ordinary prose in CommonMark.
No additional URL scanner is used. Recognized YAML/TOML headers remain opaque.

Each qualifying pair produces one zero-width original insertion point before its
right scalar, with message `Missing space between CJK and Latin text.` Full source
context is established before directive suppression at that point and inspection
line selection. No automatic edits, previews or corrected content are produced.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

No rule-specific options.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
版本2
````

Accepted input:

````markdown
版本 2
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Future correction policy: insert a space only at recognized script boundaries in prose.
This pass supplies no correction provider or fix-specific validation. MD047 remains
the sole production correction provider.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation
