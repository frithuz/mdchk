# MD013: Maximum line width

Status: planned for implementation.

Area: [Whitespace](index.md).

## Behavior

Report lines wider than the limit, counting Unicode code points and expanding tabs to four-column stops. Exempt code, tables, and indivisible URLs by default.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

length: positive integer, 80; code_blocks: boolean, false; tables: boolean, false; headings: boolean, true.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
A prose line containing more than 80 columns.
````

Accepted input:

````markdown
A short prose line.
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; reflow may change hard breaks and document layout.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
