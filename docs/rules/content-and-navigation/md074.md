# MD074: MkDocs navigation file targets

Status: planned for implementation.

Area: [Content and navigation](index.md).

## Behavior

Check local MkDocs navigation entries against the configured documentation root. Ignore remote URLs; directory entries use shared `resources.index_file`, default `index.md`, exactly once.

Use the [resource contract](../index.md#resource-dependent-checks). Resolve resources read-only; never create missing targets.

MkDocs integration must supply its documentation root within the operation resource boundary. `check_omitted` needs a complete eligible-document inventory; a partial map cannot prove omission. `check_absolute`, site-URL mappings, custom YAML, and plugin behavior require the explicit MkDocs integration contract; this resource contract does not activate them or execute plugins.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

enabled: false; config_path: string, mkdocs.yml; check_omitted: boolean, false; check_absolute: boolean, false.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
nav: [{Guide: missing.md}]
````

Accepted input:

````markdown
nav: [{Guide: guide.md}] where guide.md exists.
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only. Require an explicit MkDocs project context and a bounded parsed configuration; unavailable resources are reduced coverage.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
