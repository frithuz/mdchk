# MD081: Overuse of bold and italic text

Status: analysis and configuration implemented for CommonMark and GFM. Permanently report only.

Area: [Formatting](index.md).

## Behavior

Report each actual paragraph whose emphasized eligible characters exceed the
configured fraction of its total eligible characters, when the inclusive total
minimum is met. Each Unicode scalar in actual semantic Text counts once; an
actual Emphasis or Strong ancestor makes it emphasized. Nested and overlapping
formatting counts once. Strikethrough alone does not establish emphasis.

Exclude CommonMark whitespace (Unicode Zs plus TAB/LF/FF/CR), Unicode Cc controls
and soft/hard breaks from both populations. Combining marks, variation selectors,
format scalars (including ZWJ), LS/PS and astral symbols count individually. Do not
normalize Unicode or count bytes, graphemes or display columns. Entity and NUL
normalization use already parsed semantic values without decoding again; escaped
punctuation is excluded under the shared escaped-syntax exception.

Code, headings, actual GFM tables, raw HTML/comment syntax and protected raw
payload, recognized headers and whole image descriptions contribute nothing to
either count. Ordinary Markdown text between nonraw tags remains eligible; HTML
`<strong>` or `<em>` does not establish Markdown emphasis. Raw lifetime follows
actual openers, closers and closing tails across containers and paragraphs; image
descriptions cannot change the surrounding raw state.

Count actual link-label Text once for every link origin, including angle and GFM
bare autolinks; destinations, titles, reference identifiers and definitions do not
count. Each paragraph remains independent inside lists and block quotes. Task
markers and container prefixes are excluded by actual Content ownership. In
CommonMark, table/task-looking source follows its ordinary parsed interpretation.

Let D be eligible total and E its emphasized union. Require D > 0 and
D >= minimum_characters, then compare `float64(E) / float64(D) > maximum_ratio`
using ordinary binary64 division. Equality passes, including a rounded non-dyadic
quotient equal to its configured threshold. No epsilon or multiplication-based
rounding applies. Ratio 0 reports E > 0; ratio 1 never reports. A huge valid
minimum simply skips short paragraphs without allocating from that value.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

- `maximum_ratio`: finite number in inclusive [0, 1], default `0.5`.
- `minimum_characters`: positive integer, default `20`, applied to total D.

Integer ratios 0/1 and floating signed zero are valid. Fractional or exponent
spellings such as `20.0` or `2e1` are not integer minima. Shared `enabled` and
`allow_directives` are strict booleans. Unknown options and invalid values fail
even when disabled. Omitted or empty mappings retain default disabled availability.
See [shared configuration](../index.md#configuration-and-findings).

## Examples

Violating input with default options and enabled explicitly:

````markdown
**This entire paragraph is strongly emphasized.**
````

Accepted input:

````markdown
This paragraph contains **some** emphasized words.
````

With minimum 4, `**ab** cd` has E=2, D=4 and passes ratio 0.5 equality.
With minimum 3, `**ab** c` has E=2, D=3 and reports at ratio 0.5.

## Findings and correction policy

Emit one manual finding per violating paragraph:
`Paragraph contains excessive bold or italic text.` Its original range is the
full Paragraph Content hull: first owned source start through last owned source
end, including emphasis markup and interior container gaps. Exclude leading
container/task markers, indentation, terminal physical ending and paragraph-final
trimmed SPACE/TAB. Positions use original one-based Unicode-scalar columns with
exclusive ends; transformed tokens and CRLF stay atomic.

Count the whole original paragraph before filtering. Only its range START selects
directive state. Later inline enable/disable cannot split or recompute counts or
retroactively change that state. Inspection line selection follows full analysis
and includes a finding when the selected lines intersect its full range.

Emphasis conveys author intent. MD081 never generates edits, previews, correction
eligibility or corrected content. MD047 remains the sole production correction;
its candidate/saved reanalysis can retain manual MD081 findings.

## Validation

Frozen independently authored fixtures cover original bytes, scalar counts,
thresholds, protected regions, nesting, formats, Unicode, endings and exact ranges.
Additional checks cover strict options, source/operation authority, filtering,
concurrency and finite work/node/time controls with atomic failure withholding.
