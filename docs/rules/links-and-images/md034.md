# MD034: URLs without link markup

Status: analysis and configuration implemented for CommonMark and GFM. Findings
are manual; automatic URL wrapping remains planned.

Area: [Links and images](index.md).

## Behavior

Report HTTP, HTTPS, or FTP URLs in prose without explicit link markup. Exclude URLs inside explicit inline links, reference links, angle-delimited autolinks, HTML attributes, code, or definitions.

A bare GFM autolink still lacks explicit markup and remains eligible for this rule. Use the parser's link source kind to distinguish it from an angle-delimited autolink; the presence of a link node alone does not exempt the URL.

Schemes are case-insensitive. In ordinary text, an exact original `http://`,
`https://` or `ftp://` spelling begins a candidate outside a word. It requires a
nonempty authority containing a letter or digit; localhost and Unicode host/path
text are included. A candidate stays inside one actual prose owner and one line.
Whitespace, controls, angle brackets and quotes end ordinary-text candidates.
Explicit link labels remain exempt from URL findings, while their actual raw
HTML openers and closers still affect protection of surrounding prose. Image
alternatives remain opaque. Code, recognized metadata, comments, raw HTML
lifetimes and reference definitions remain protected. Decoded entities or escapes
cannot create a scheme. Original entity/escape contributions inside a URL remain
atomic and retain their complete original byte ranges.

Trailing `?!.,:*_~`, excess closing parentheses and entity-shaped `&alnum;`
suffixes are excluded repeatedly; balanced parentheses and interior punctuation
remain. GFM HTTP(S) links use the parser's original `bare-gfm` envelope and its
established punctuation boundaries. Other GFM forms such as `www.`, email,
`mailto:` and `xmpp:` are outside this rule even when their semantic destination
contains a generated HTTP scheme. Their original visible bytes can still belong
to the authority or payload of a surrounding scoped URL, such as
`ftp://user@example.org/pub`; a synthetic destination never supplies its scheme.
This does not alter either dialect's parser recognition rules.

Each finding covers the complete original URL and says
`URL lacks explicit link markup.` It uses original byte offsets and one-based
Unicode scalar columns. Recognition precedes inspection focus and suppression.
Unknown necessary source mapping or raw context withholds the complete inventory
with reduced coverage, including earlier provisional findings; unknown context
after the last potential URL does not discard established findings.

## Configuration

Default enablement: Enabled.

No rule-specific options.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
Visit https://example.org
````

Accepted input:

````markdown
Visit <https://example.org>
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

No MD034 edits, replacement documents or fix proposals are produced in Pass 1.

Future correction may wrap a correctly delimited URL in angle brackets while
preserving adjacent punctuation, after shared preservation checks succeed.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For any future corrections, verify preserved meaning and a second fix run with
no further changes.

Run the bare-URL and angle-delimited examples in both CommonMark and GFM modes. In GFM, assert the different link source kinds and verify that only the bare URL is reported. Preserve the existing HTTP, HTTPS, and FTP scope and punctuation boundaries.
