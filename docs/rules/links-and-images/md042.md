# MD042: Links without destinations

Status: analysis and configuration implemented for CommonMark and GFM.

Area: [Links and images](index.md).

## Behavior

Report actual inline Links whose parser-semantic destination is empty or exactly
`#`. Destinations are decoded once by the selected parser: `\#`, `&#35;`, `&#x23;`
and `&num;` mean a lone fragment marker. Do not trim values or percent-decode them;
`%23`, `##`, `#part`, `guide.md#` and a literal angle-destination space are accepted.
A title does not supply a destination. Empty link labels remain eligible.

Images and all their alternative-text descendants are excluded. A surrounding
Link containing an Image remains eligible. Full, collapsed and shortcut reference
Links, their definitions, autolinks, malformed bracket text, code, comments,
metadata and actual raw HTML payload are excluded. Original raw HTML state at the
destination remains authoritative, including tags opened or closed in its visible
label. Ordinary markup or a code span inside a label does not hide its destination.

Report `Link destination is empty or only a fragment marker.` at the smallest
original destination range: an empty destination uses its zero-width insertion
point, and a lone fragment marker selects its complete original spelling,
including any escape/entity bytes. For `[Guide]()` this is byte range `[8,8)`;
for `[Guide](#)` it is `[8,9)`, and for `[Guide](&#35;)` it is `[8,13)`.
Coordinates use one-based Unicode code-point columns with exclusive ends;
container prefixes and surrounding delimiters are excluded. Unknown required
context withholds the complete MD042 inventory with explicit reduced coverage.

## Configuration

Default enablement: Enabled.

No rule-specific options.

All rules also accept the [shared settings](../index.md#configuration-and-findings).
Unknown options and invalid values reject even when the rule is disabled.

## Examples

Violating input:

````markdown
[Guide]()
[Guide](#)
[Guide](<>)
[Guide](&#35;)
````

Accepted input:

````markdown
[Guide](guide.md)
[Section](#section)
[Encoded](%23)
![Image]()
[Reference][id]

[id]: <>
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>`
describe source characters rather than literal Markdown.

## Correction policy

Permanently report only; the destination must be supplied by the author. MD042
has NoFix metadata and produces no automatic edits, previews, corrected content
or correction eligibility.

## Validation

Reusable literal analysis fixtures cover examples, configuration boundaries,
protected content, exact destination decoding, reference/image exclusions, nested
containers, LF/CRLF/CR and precise original diagnostic ranges for both formats.
Engine, inspection and compiled CLI checks verify defaults, shared directives,
unchanged source and manual findings. MCP adapter parity remains downstream in
#196, #200 and #206.
