# MD054: Link and image representation style

Status: planned for implementation.

Area: [Links and images](index.md).

## Behavior

Require links and images to use one of the allowed representations. Recognize inline, full reference, collapsed reference, shortcut reference, and autolink forms separately.

Both bare GFM autolinks and angle-delimited autolinks use the `autolink` style. Retain their distinct parser source kinds for [MD034](md034.md) and source-preserving corrections; they do not add a sixth configuration style. Whether a source form is recognized as a link depends on the selected dialect.

The examples use allowed_styles: [full_reference]. With the default list of all styles, either example is accepted.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

allowed_styles: nonempty list of representation names; default all five.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
[Guide](guide.md)
````

Accepted input:

````markdown
[Guide][manual]

[manual]: guide.md
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

With allowed_styles [full_reference], convert only if labels, destinations, titles, and definition placement can be preserved unambiguously.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.

Verify that bare and angle-delimited GFM autolinks both map to `autolink` and retain distinct source kinds so MD034 can report only the eligible bare URLs. In CommonMark mode, a bare URL is ordinary prose and is not a link representation checked by MD054.
