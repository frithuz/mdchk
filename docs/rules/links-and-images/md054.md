# MD054: Link and image representation style

Status: analysis and configuration implemented for CommonMark and GFM. Findings
are report-only; there are no automatic fixes yet.

Area: [Links and images](index.md).

## Behavior

Require links and images to use one of the allowed representations. Recognize inline, full reference, collapsed reference, shortcut reference, and autolink forms separately.

Both bare GFM autolinks and angle-delimited autolinks use the `autolink` style. Retain their distinct parser source kinds for [MD034](md034.md) and source-preserving corrections; they do not add a sixth configuration style. Whether a source form is recognized as a link depends on the selected dialect.

Each link and image the parser recognizes gets one style from its parser
origin: inline `[text](url)` is `inline`, `[text][label]` is `full_reference`,
`[text][]` is `collapsed_reference`, `[text]` with a matching definition is
`shortcut_reference`, and both `<https://example.com>` and a bare GFM URL are
`autolink`. Images use the same four non-autolink styles. Whether a reference
resolves does not change its style.

Each link or image whose style is not in `allowed_styles` produces one finding.
The range covers the original link or image, from `[`, `![` or `<` (or the
first character of a bare URL) through the closing `)`, `]` or `>` (or the last
character of the bare URL). A link that spans lines keeps any container prefix
bytes between its lines. The message names the style found:
`Link representation style "<style>" is not allowed.` for links and
`Image representation style "<style>" is not allowed.` for images.
Coordinates use original bytes and Unicode scalar columns, and never split a
CRLF line ending. A real suppressed finding counts as used for MD087.

Links in paragraphs, headings, block quotes, list items and table cells are
checked. Nested constructs are checked on their own: an image inside a link
label and a link inside an image description each produce their own finding,
and the ranges overlap. Code spans, code blocks, HTML blocks, inline raw HTML
lifetimes and tails, and link reference definitions are never checked, and
bracket text that the parser does not recognize as a link, such as
`[not a link]` without a definition, is ordinary prose.

When a link's parser origin or the raw HTML state is unknown, the whole
inventory is withheld instead of guessed. The coverage message is
`Link representation context is unavailable; the complete MD054 inventory is withheld.`

The examples use allowed_styles: [full_reference]. With the default list of all styles, either example is accepted.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

allowed_styles: nonempty list of representation names; default all five.

All rules also accept the [shared settings](../index.md#configuration-and-findings).

## Examples

Violating input:

````markdown
[Guide](guide.md)
````

Accepted input:

````markdown
[Guide][manual]

[manual]: guide.md
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

No MD054 edits, replacement documents or deferred fix proposals are produced in
this pass. Corrections remain planned.

With allowed_styles [full_reference], convert only if labels, destinations, titles, and definition placement can be preserved unambiguously.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.

Verify that bare and angle-delimited GFM autolinks both map to `autolink` and retain distinct source kinds so MD034 can report only the eligible bare URLs. In CommonMark mode, a bare URL is ordinary prose and is not a link representation checked by MD054.
