# MD004: Bullet marker style

Status: analysis and configuration implemented for CommonMark and GFM.

Area: [Lists](index.md).

## Behavior

Require each actual parsed unordered item marker to match the configured character.
In `consistent` mode, the first actual bullet chooses one marker for the entire
document, across separate lists, nesting and blockquotes. Ordered markers do not
choose or reset it; their actual nested bullets still participate. Each document
starts independently. Empty, definition-only and task items retain real bullets.

Full original context chooses the baseline, including bullets in disabled or
suppressed intervals before a later enable directive. Findings then follow normal
start-anchor suppression. Each mismatch selects exactly the original one-byte
bullet, excluding indentation, container prefixes, padding and task checkboxes.

The actual parser decides list ownership and thematic-break/Setext precedence.
Marker-looking payload in code, HTML, comments or recognized metadata is opaque;
escaped text and lazy continuation text are not redispatched as list items.

## Configuration

Default enablement: Enabled.

`marker`: `consistent`, `asterisk`, `plus`, or `dash`; default `consistent`.
Explicit modes require `*`, `+` or `-` respectively, including the first item.
Values are exact and case-sensitive. Invalid/null values and unknown options are
configuration errors even while the rule is disabled.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
- One
* Two
````

Accepted input:

````markdown
- One
- Two
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Analysis is manual: MD004 emits no edits or automatic preview authority. The
catalog retains planned correction metadata for a future pass, which would
replace only parsed bullet markers and verify unchanged list structure. Existing
MD047-only newline candidates are reanalyzed with the same immutable marker option.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
