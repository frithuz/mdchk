# MD019: Extra spaces after opening hashes

Status: analysis, configuration and automatic correction implemented for CommonMark and GFM. A separator containing a tab stays a manual finding.

Area: [Headings](index.md).

## Behavior

Report more than one space between an ATX heading's opening hashes and content. Ignore a heading only when the parser-trimmed raw content is empty, including
empty closed headings such as `#   ###`. A comment, HTML tag, empty-label link or
image, code, markup, entity or NBSP remains raw content even when visible text is
empty. Setext headings, missing-separator candidates and seven-hash prose are
outside this rule.

Count literal U+0020 spaces across the complete parser-confirmed opening
separator. Tabs neither count nor expand; MD010 separately governs tab bytes.
This is mdchk's recorded interpretation of “more than one space” for mixed
separators. For example, `#<TAB><TAB>Title`, `#<TAB><SPACE>Title` and
`#<SPACE><TAB>Title` pass MD019; `#<SPACE><TAB><SPACE>Title` violates.

Emit one finding from the second ASCII space through immediately after the last
ASCII space. This smallest contiguous excess span excludes leading/trailing tabs;
intervening tabs remain only when needed to cover the excess spaces. `##  Install`
reports bytes [3,4), line 1 columns 4–5. `#<SPACE><TAB><SPACE>Title` reports [3,4);
`#<SPACE><SPACE><TAB><SPACE>text` reports [2,5). Nested `> - ##   雪` reports [7,9),
line 1 columns 8–10. Tabs count as one public diagnostic column.

Closed headings remain in MD019 scope. [MD021](md021.md) independently checks
both closed-heading gaps; both IDs may report the same opening excess.

## Configuration

Default enablement: Enabled.

No rule-specific options.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the mdchk contract.

## Examples

Violating input:

````markdown
##  Install
````

Accepted input:

````markdown
## Install
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

`fix` and `fix --dry-run` reduce a separator made up only of ASCII spaces to one space, by deleting the finding's span: the second through last space. `##  Install` becomes `## Install`.

Tab exception: a separator containing any tab gets no edit and its finding has `fix_available: false`, however the spaces are arranged. For example, `#<TAB><SPACE><SPACE>Mixed` and `#<SPACE><SPACE><TAB><SPACE>text` stay manual. MD010 governs tab bytes, and no result is defined for a mixed separator.

When [MD021](md021.md) reports the same opening excess, each rule proposes the same edit. It is applied once, and the change credits both rules. Enablement and directives apply to each rule separately. If one ID is disabled, the other can still correct the gap; if both are disabled, the bytes stay.

A document that opens with a complete `---` or `+++` block that isn't recognized, because `frontmatter.enabled` is false or the block's format isn't in `frontmatter.formats`, gets no edits anywhere, and its findings have `fix_available: false`. A leading thematic break paired with a later one has the same shape. `frontmatter.enabled: true` restores body corrections for real headers.

Protected contexts stay unchanged, and `fix_available` is true only for findings the correction handles. An independent checker proves that only excess spaces changed and that heading level, text, anchors and containers are preserved.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF, CRLF and CR input, and precise diagnostic ranges. Correction tests cover preview and saved modes, the tab exception, directives, forged proposals, composition with MD047, preserved meaning and a second fix run with no further changes.
