# MD043: Required heading outline

Status: analysis and configuration implemented for CommonMark and GFM. Disabled by default; report-only, with no edits or previews.

Area: [Headings](index.md).

## Behavior

Require headings to match a configured ordered outline of level and visible text. An asterisk entry permits zero or more intervening headings.

The examples use headings: ["# Guide", "## Install", "## Usage"]. Without a configured outline, this rule produces no findings.

All actual parsed body headings participate in source order across containers and
disabled intervals. Compare level and the parser's exact visible text, including
its established text, code, formatting, link/image and raw-region semantics.
Do not fold case, normalize Unicode, trim or collapse whitespace. Style alone does
not differ: matching ATX, closed ATX and Setext headings are equivalent. A multiline
Setext visible newline is significant and cannot match a single-line descriptor.
Protected fake headings and recognized metadata are not sequence entries; no
virtual metadata title is added.

Match the whole sequence. Leading, trailing and consecutive `*` entries are valid;
`*` can consume zero headings and retains alternate matching anchors. For example,
`["# A", "*", "# B", "# C"]` accepts A, B, B, C as well as A, B, C.

When a match is impossible, use a deterministic minimum-unit-edit alignment:
exact matches and wildcard empty/consume transitions cost zero; substitution,
missing expected and unexpected actual headings cost one. Among equal optimal
paths prefer exact match, wildcard advance, wildcard consume, substitution,
missing expected, then unexpected actual. Report only the first positive-cost
edit on that chosen path, without cascading or realigning after suppression.
These are conservative project comparison choices, not an upstream parity claim.

Substitution or an unexpected heading selects its complete original raw label
(an empty heading's label can be a point). A missing heading uses a zero-width
point at the next actual heading's original envelope start, or original EOF if no
heading remains. Envelope ownership, not a guessed physical/container prefix,
determines the point. The published missing Install case reports before Usage.
The chosen original start governs directive suppression.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

headings: list of heading strings or asterisk entries, empty; an empty outline performs no check.

Each entry is exactly `*`, or one through six leading ASCII `#` bytes followed by
one ASCII space and a literal expected-visible suffix, which may be empty. Extra
spaces after the first separator belong to that suffix. Reject indentation, a
missing/tab separator, seven leading hashes, CR and LF, including on disabled
rules; errors identify the offending list element. `# ` is an empty-text heading,
`# *` expects a literal star, and `* ` is invalid. The suffix is not Markdown:
`# **Guide**` expects literal stars, while `# Guide` can match an actual formatted
Guide heading. Do not decode entities/escapes or strip option closing hashes.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the mdchk contract.

## Examples

Violating input:

````markdown
# Guide

## Usage
````

Accepted input:

````markdown
# Guide

## Install

## Usage
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; configured outline [# Guide, ## Install, ## Usage] requires the missing section.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
