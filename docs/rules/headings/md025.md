# MD025: Multiple document titles

Status: planned for implementation.

Area: [Headings](index.md).

## Behavior

Report a second heading at the configured title level. A recognized frontmatter title may count as the first title.

Only the exact top-level title key with a decoded nonblank string counts. Missing, blank or non-string title values do not count. The existing frontmatter_title options remain opt-in; MD001 uses a virtual H1, MD025 counts one title at its configured title level, and MD041 accepts the title as satisfying its existing opening-heading requirement.

See the [metadata contract](../../engineering/frontmatter.md#metadata-values-and-corrections).

## Configuration

Default enablement: Enabled.

level: integer 1 through 6, 1; frontmatter_title: boolean, false.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the planned mdchk contract.

## Examples

Violating input:

````markdown
# Guide

# Usage
````

Accepted input:

````markdown
# Guide

## Usage
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; choosing the title or changing levels is semantic.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
