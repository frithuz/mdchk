# MD083: Text corrupted by encoding mismatch

Status: analysis and configuration implemented for CommonMark and GFM;
automatic correction is not offered (report-only).

Area: [Encoding](index.md).

## Behavior

Report configured suspicious character sequences associated with incorrectly decoded UTF-8 text. Findings indicate suspicion rather than certain corruption.

Sequences compare against the original UTF-8 bytes, with no case folding,
normalization or trimming, so `ã` does not match `Ã`. There are no word
boundaries: a sequence matches anywhere, including inside a word such as
`cafÃ©`. A sequence never crosses a physical line, an entity or an escape, so
`&Atilde;` is not matched.

Scan left to right; at each start report the sequence reaching the farthest
original endpoint, then continue after it. Findings never overlap: sequences
`[Ã, Ã©]` report `Ã©` in `cafÃ©` once. Duplicate sequences give one finding per
occurrence. The fixed message is `Text may be corrupted by an encoding mismatch.`
and the range covers exactly the matched original bytes.

Prose is what [MD061](../content-and-navigation/md061.md) analyzes: Exact,
touching, single-line Text in paragraphs, headings, GFM table cells, authored
link labels and image alternatives, including inside block quotes and list items
at any depth. Code spans, fenced and indented code, HTML blocks, inline HTML and
raw-tag lifetimes, angle autolinks, GFM bare links, link destinations, titles,
reference definitions and recognized frontmatter are protected. Unreliable
required syntax produces affected incomplete coverage.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

sequences: string list, [Ã, Â, â€]; match in prose only.

Every sequence must be valid UTF-8, even when disabled. Empty sequences are
inert; duplicates are harmless. An empty list, or one holding only empty
sequences, means no findings.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the mdchk contract.

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; do not attempt lossy encoding repair.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
