# MD084: Hidden or discouraged Unicode characters

Status: analysis and configuration implemented for CommonMark and GFM;
automatic correction is not offered (report-only).

Area: [Encoding](index.md).

## Behavior

Report discouraged invisible characters in prose: U+200B, U+FEFF within the body, and U+202A through U+202E. Exempt explicitly allowed code points.

The reported set is exactly U+200B ZERO WIDTH SPACE, U+202A through U+202E
(the bidirectional embedding and override controls) and U+FEFF ZERO WIDTH
NO-BREAK SPACE. A U+FEFF at byte offset 0 is a byte order mark and is never
reported; any later U+FEFF is. Joiners such as U+200C and U+200D, U+2060 and
other format characters are not reported.

Each occurrence is one finding, so adjacent characters give separate findings.
The fixed message is `Hidden or discouraged Unicode character U+XXXX.`, with the
code point in four uppercase hexadecimal digits, and the range covers exactly
the character's three original bytes.

Prose is what [MD061](../content-and-navigation/md061.md) scans, which is what
[MD044](../formatting/md044.md) analyzes with code blocks off: Text in
paragraphs, headings, GFM table cells, authored link labels and image
alternatives, including inside block quotes and list items. Code spans, fenced
and indented code, HTML blocks, inline HTML and raw-tag lifetimes, angle
autolinks, GFM bare links, link destinations, titles, reference definitions and
recognized frontmatter are protected. Only literal characters are reported:
entities such as `&#x200B;` and backslash escapes are visible in the source and
are not decoded into findings. Unreliable required syntax produces affected
incomplete coverage.

## Configuration

Default enablement: Disabled; enable explicitly for projects that require this check.

allowed_codepoints: hexadecimal string list, empty. Do not flag joiners used in scripts by default.

Each entry is one or more hexadecimal digits of either case, without a `U+` or
`0x` prefix, naming a Unicode scalar; surrogates and values above `10FFFF` are
rejected, even when the rule is disabled. Entries match by numeric value, so
`200b`, `200B` and `00200B` all allow U+200B. Allowing a code point outside the
reported set has no effect.

All rules also accept the [shared settings](../index.md#configuration-and-findings). The defaults here are the mdchk contract.

## Examples

Violating input:

````markdown
word<U+200B>word
````

Accepted input:

````markdown
wordword
````

Angle-bracket placeholders such as `<SPACE>`, `<TAB>`, `<EOF>`, and `<NEWLINE>` describe source characters rather than literal Markdown. Prose examples describe cases that cannot be represented directly in a UTF-8 document.

## Correction policy

Report only; removing directional or invisible characters may change language semantics.

Any correction must satisfy the [shared preservation contract](../index.md#implementation-contract). Report remaining findings after checking the corrected document again.

## Validation

Cover the examples, every option, protected content, nested containers, LF and CRLF input, and precise diagnostic ranges. For corrections, verify preserved meaning and a second fix run with no further changes.
